This repository hosts the UCA TF13 website (https://utf13-reports.ucaiug.io) for published and interim releases of the CIM Grid package: the UML model of the current International Standard, IEC 61970-301 Ed 7.1 (CIM17v40), and the interim releases toward the next CIM release, CIM18, the basis for the next editions of IEC 61970-3xx and IEC 61970-4xx. Each release is published with its release notes and a [cim-compare](https://cim-compare.ucaiug.io) report of what changed. These reports and associated artifacts are made available by UCAIug and licensed under the Apache 2.0 open source license.
